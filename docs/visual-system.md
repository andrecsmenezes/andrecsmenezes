# Visual system

The profile uses the same core visual language as the ACSMTI website.

## Canonical palette

| Token | Value | Role |
|---|---|---|
| Paper | `#fdf9ee` | Primary canvas |
| Paper alt | `#fffdf8` | Elevated/light surfaces |
| Ink | `#171418` | Primary text and strong contrast |
| Muted | `#625b5b` | Secondary text |
| Orange | `#f68543` | Brand accent |
| Coral | `#f6535f` | Brand accent |
| Pink | `#ef1f63` | Brand accent |
| Wine | `#9d1348` | Deep accent / emphasis |

The values are copied from the canonical ACSMTI design-token source rather than sampled from screenshots.

## Brand mark

`assets/acsmti-mark.svg` is derived from the public ACSMTI favicon asset and preserves the same mark used by the website header.

## Profile treatment

The GitHub profile intentionally uses the brand system without reproducing the website layout. The goal is visual continuity:

- warm paper surfaces instead of generic dark developer cards;
- ink-first typography;
- orange → coral → pink → wine accent progression;
- restrained gradients and radii;
- low visual noise;
- engineering content remains the primary hierarchy.
